判定标准（点开）

只问一件事：如果我要做这个产品，这个仓库值不值得我读 10 分钟？

Y 三条同时满足：同一用户问题（不是同一技术、不是同一个词）· 读完 README 能抄到至少一个具体设计决定 · 是可运行软件/库/模板，不是列表/教程/论文。

N 命中任一即可：只共享关键词 · 是基础设施但不是这个产品形态 · 是列表/教程/资料 · 同词异义。

U 仅当描述不足以判断、且你不愿多花 1 分钟去看。控制在 20% 以内。

「归档 / 停更」不用你判断——从描述里看不出来，由脚本事后过滤。

禁止：点开 README 再决定 · 用 star 数判断 · 参考插件输出。只看这里的 repo + 描述。

键盘：J/↓ 下一条 · K/↑ 上一条 · 1 = Y · 2 = N · 3 = U
